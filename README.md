# Daria Melnikova — 3D, CAD & Product Prototyping

An editorial portfolio for Daria Melnikova, focused on compact physical
products, CAD systems, product visualisation, embedded hardware and
reconstruction.

## Routes

- `/` — selected work, capabilities, process and contact
- `/work` — filterable project archive
- `/work/smartmotion` — verified SmartMotion hardware case
- `/work/modular-system` — modular CAD study
- `/work/eeg-wearable` — wearable product visualisation
- `/work/photogrammetry` — reconstruction case in progress
- `/about` — profile, tools and availability

## Local development

The project requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

Useful checks:

```bash
npm run check
npm run lint
npm run build
```

The production build is generated by Vinext and the Cloudflare Vite plugin.
Project likes are stored in the bound `DB` D1 database. Without that binding,
read requests safely return zero and mutations remain unavailable.

## Content structure

The home page presents work on three tracks, set by each project's `track`
field in `lib/projects.ts`:

- **A / Work projects**: built with a team or lab
- **B / Personal projects**: self-initiated builds
- **C / Ideas & concepts**: explored visually, not built yet

Full cases follow a maker-portfolio story: problem → idea → how it was built →
result → what I learned. Projects without final media yet live in
`projectDrafts` and render as compact cards with an image placeholder.
See [`CASE_TEMPLATE.md`](CASE_TEMPLATE.md) for how to add or promote a project.

## Deployment

The site is deployed through the connected OpenAI Sites project. Its project
identifier is kept in `.openai/hosting.json`, while the deployable build copies
that metadata and the D1 migration into `dist/.openai`.
